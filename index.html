教学结论： 在这个简化模型中，若 c<r，种群仍存在正的长期平衡 N*=K(1−c/r)；若 c>r，种群会持续向 0 衰减； c=r 是临界阈值，此时种群也会下降，但接近 0 时下降会越来越慢。
模型边界： 本工具用于课堂理解“增长—清除—平衡”的关系，并非对真实互花米草治理效果的现场预测。 模型假设 K、r 与 c 在模拟期内固定，且暂不考虑种子库、外来迁入、空间扩散、季节性、清除效率差异与重复萌发等现实因素。
